# DTM 導入手引き — AIカバー制作のための DAW ワークフロー

作成: 2026-08-16 / 対象読者: 本リポジトリで SVC・RVC・Irodori-TTS の音声を作り、
DAW 上で手動コンピング（切り貼り・修正）して1曲に仕上げたい人。

関連: `data/output/luca_svc/`（ステム置き場）、CLAUDE.md「音源分離」節、
Seed-VC / Applio(RVC) のラッパー各種。

---

## 1. どの DAW を使うか（無料重視の結論）

| DAW | 費用 | 向き | 備考 |
|---|---|---|---|
| **REAPER**（第一推奨） | 評価版は全機能・期限後も動作継続（正規は$60） | ◎ | AIカバー制作の事実上の標準。軽量・タイムストレッチ/ピッチ編集が強力・日本語化可 |
| **Waveform Free**（完全無料の第一候補） | 完全無料・機能制限ほぼ無し | ○ | Tracktion 製。VST3 使用可。UI に癖があるが必要機能は全部ある |
| Cakewalk / Sonar | 無料版の提供形態が流動的 | △ | 旧 Cakewalk by BandLab は入手不可になる場合あり。導入時点の配布状況を要確認 |
| Studio One Prime | 無料 | △ | **サードパーティ VST が使えない**ため、無料プラグイン活用前提の本ワークフローには不向き |
| LMMS / Audacity | 無料 | △ | LMMS は打ち込み向きでオーディオコンピングが弱い。Audacity は波形編集機として補助利用なら有用 |

**結論**: まず **REAPER** を入れる（評価版で始めてよい。継続利用するなら$60）。
完全無料に拘るなら **Waveform Free**。以下の手順は REAPER 前提で書くが、
概念はどの DAW でも同じ。

## 2. 初期設定（REAPER）

1. https://www.reaper.fm/ から Windows 64bit 版をダウンロード・インストール
2. `Options > Preferences > Device` で ASIO ドライバを選択
   （オーディオ IF が無ければ ASIO4ALL または WASAPI 共有でも可）
3. プロジェクト設定: **44.1kHz / 24bit**
   - 本リポジトリの生成物（Seed-VC 出力・ミックス済み WAV）は 44.1kHz。
     48kHz プロジェクトに読むと自動リサンプルされるので 44.1kHz に合わせるのが無難
4. 日本語化パッチ（REAPER 公式フォーラム配布）は任意

## 3. 本リポジトリとの連携ワークフロー

### 3.1 トラック構成（テンプレート推奨）

| トラック | 素材 | 場所 |
|---|---|---|
| Inst | BS-RoFormer の Instrumental | `data/output/luca_svc/vocals/` ほか |
| AI Vocal (base) | Seed-VC / RVC 変換済みボーカル | `data/output/luca_svc/converted*/` |
| Vocal fix | 差し替え用の部分変換テイク | 後述のループで生成 |
| 素材 (breath/語尾) | 元歌手の実録素材 | フレーズ素材ライブラリ（生成可能、依頼すれば作成） |
| Reference | 原曲ミックス | `data/input/` |

- 変換ボーカルとインストは**同一の元音源から分離しているので頭出し不要**
  （0秒に置けばサンプル単位で一致する）
- Reference トラックはミュートしておき、tab 切り替えで聴き比べに使う

### 3.2 破綻箇所の差し替えループ（本ワークフローの核心）

1. AI Vocal (base) を通しで聴き、破綻箇所（発音崩れ・抽出漏れ・ハモリ混入）に
   マーカーを打つ
2. その区間の**ガイド音声**を用意する（次節）
3. ガイド WAV を書き出し → RVC で声質変換（変換窓口スクリプトは依頼すれば用意する。
   基本は Applio の `core.py infer --input-path <wav> --output-path <wav>
   --pth-path <model.pth> --index-path <index>`）
4. 変換結果を Vocal fix トラックの該当位置に貼り、クロスフェード（10〜40ms）で
   base と繋ぐ
5. 繋ぎ目が目立つ場合: 前後のブレス素材を挟む / フェード曲線を等パワーに変更 /
   ピッチ補正で前後と揃える

### 3.3 ガイド音声の作り方（品質順）

1. **自分で歌って録る** — タイミング・抑揚を完全制御できるので最高品質。
   音程が不安でも RVC はピッチを保持するので、ピッチ補正（後述）してから変換すればよい
2. **Synthesizer V Studio Basic（無料）** — 歌詞とメロディを打ち込んで合成。
   無料ボイスでもガイドとしては十分。タイミングを原曲に合わせて打ち込む
3. **OpenUtau（無料）** — UTAU 系。慣れていればこちらでも可
4. 原曲ボーカルの別モデル再抽出（抽出漏れが原因の場合、別の分離モデルで
   その区間だけ再抽出すると拾えることがある）

### 3.4 キー・テンポの取り扱い

- キー変更した変換ボーカル（例: -1半音版）を使う場合、**インストも同じだけ**
  シフトする必要がある。REAPER ならアイテム選択 → `Shift+9/0` で半音単位、
  またはアイテムプロパティで pitch shift（アルゴリズムは élastique Pro を選ぶ）
- インストのキーシフトは音質が劣化するので、基本は**原曲キーの変換ボーカル**
  （auto-f0-adjust オフ）を使うのが安全

## 4. 無料プラグイン（ボーカル処理の定番）

| 用途 | プラグイン | 備考 |
|---|---|---|
| ピッチ補正 | **Graillon 2**（Auburn Sounds） | 無料版でリアルタイム補正可。ガイド録音の音程直しに |
| ピッチ補正 | MAutoPitch（Melda） | ケロ味が欲しい時にも |
| EQ | TDR Nova | ダイナミック EQ。刺さる帯域の抑制に |
| コンプ | REAPER 付属 ReaComp | 十分高性能 |
| ディエッサー | TDR Nova で代用可 / ReaXcomp | |
| リバーブ | **Valhalla Supermassive** | 無料とは思えない品質。ボーカル用ホール/プレートに |
| ダブラー | iZotope Vocal Doubler | サビの厚み出し |
| ラウドネスメーター | Youlean Loudness Meter | 書き出し前の LUFS 確認 |

## 5. ボーカルミックスの基本チェーン（順番ごと）

1. **クリップ整理**: 無音部のカット、クロスフェード、ブレスの音量調整
2. **ピッチ補正**（必要箇所のみ。AI 変換済み音声は原則ピッチが原曲通りなので軽く）
3. **ハイパスフィルタ**: 80〜100Hz 以下をカット（分離残渣の低域ノイズ除去）
4. **減算 EQ**: こもり（250〜400Hz）・刺さり（2.5〜4kHz）を -2〜-4dB 程度
5. **コンプ**: レシオ 3:1、ゲインリダクション 3〜6dB 目安
6. **ディエッサー**: 歯擦音（6〜9kHz）
7. **空間系（センド）**: プレートリバーブ + 1/8 ディレイを薄く。
   AI 変換音声はドライすぎることが多いので、原曲の残響感に合わせる
8. **オートメーション**: サビで +1〜2dB、語尾のフェードなど

インスト側は基本触らない（分離済みの完成 2mix なので）。ボーカルが埋もれる場合のみ
2〜4kHz を 1dB ほどシェルフで下げる「ボーカル用の穴あけ」をする。

## 6. 書き出し

- フォーマット: WAV 44.1kHz 24bit（配布しない前提。個人試聴なら FLAC でも）
- ラウドネス目安: -14 LUFS integrated（ストリーミング基準に合わせた個人試聴用）、
  ピーク -1.0dBTP
- REAPER: `File > Render`、Master mix、tail 3秒

## 7. このリポジトリ側で自動化できること（依頼すれば作る）

- **フレーズ素材ライブラリ**: 分離ボーカルを無音区切りで自動分割し、
  開始/終了秒・長さ・中央値ピッチ（音名）付き CSV と共に出力
- **RVC 変換窓口**: フォルダに WAV を置くと全部変換して返すバッチ
- **区間再抽出**: 指定秒数区間だけ別の分離モデルで再抽出
- **De-Reverb 素材**: UVR 系モデルでドライ化した差し替え用素材
