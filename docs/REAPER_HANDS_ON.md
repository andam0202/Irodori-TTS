# REAPER 実操作ガイド — AIカバー制作の手順を全部書く

作成: 2026-08-16 / 対象: REAPER を初めて触る人が、本リポジトリの生成物
（変換ボーカル + インスト + 差し替えテイク）を1曲に仕上げるまで。
`docs/DTM_GUIDE.md`（全体方針・DAW選定・プラグイン一覧）の実操作版。

このファイルは「あなたが実際にクリック/キーを押す操作」を、迷わないよう順に全部書く。
ショートカットは REAPER 既定（Windows）。**太字**が実際の操作。

---

## 0. 用語と画面の見方（最初に10分だけ）

- **トラック**: 縦に積まれる音の帯。左端の縦長パネルが「トラックパネル」（音量・ミュート等）、
  右の広い領域が「アレンジビュー」（時間軸に沿って音のかたまりを置く場所）
- **アイテム**: アレンジビューに置かれた音のかたまり（1つの WAV = 1アイテム）。
  角をドラッグで長さ変更、本体ドラッグで移動
- **再生ヘッド / 編集カーソル**: 縦線。クリックした位置に編集カーソルが立つ。
  **Space** で再生/停止、**Home** で先頭へ
- **トランスポート**: 下部の再生ボタン群。ここで再生位置・テンポ表示を見る
- マウス: ホイールで横スクロール、**Ctrl+ホイール**で横ズーム、
  **Ctrl+Alt+ホイール**で縦ズーム

## 1. プロジェクトを作る

1. REAPER 起動 → **File > New Project**（Ctrl+N）
2. **File > Save Project As**（Ctrl+S）→ 曲名フォルダを作って保存
   （例: `顔_luca_cover`）。以降 **Ctrl+S** をこまめに
3. 右下 or **File > Project Settings**（Alt+Enter）で
   **Sample rate = 44100**、Project BPM は今は気にしない
   - 理由: 本リポジトリの WAV は 44.1kHz。合わせておくと再サンプルされない

---

## 2. 素材を読み込む（インスト + AIボーカル）

1. アレンジビューの**空いている場所をダブルクリック**するとトラックが1本できる…
   のではなく、**素材を直接ドラッグ&ドロップ**するのが早い
2. エクスプローラで以下を開く:
   `data\output\luca_svc\`
3. **インスト**をアレンジビューにドラッグ:
   `vocals\kao_avemujica_(Instrumental)_..._bs_roformer_....wav`
   - ドロップ位置は**一番左端（時間0）に吸着**させる。ドロップ後、
     アイテムを選択して **アイテム左端が 0:00.000 か**を下部の表示で確認。
     ズレたら本体をドラッグして 0 に戻す（**アイテムを選択 → 数値入力は
     ダブルクリックで Item Properties → Position=0**）
4. **AIボーカル**を別トラックにドラッグ:
   `kao_luca_cover_mix_key0_cfg1_melband.wav` は既にミックス済みなので、
   **仕上げをやり直したいなら「変換ボーカル単体」**を使う:
   `converted_melband_kao_avemujica\vc_*.wav`
   これも**時間0**に置く
   - 変換ボーカルとインストは同じ元音源から分離しているので、
     両方0に置けばサンプル単位で合う（頭出し不要）
5. トラック名をダブルクリックして改名: `Inst` / `AI Vocal`

### トラックの基本操作（左のトラックパネル）
- **M** ボタン=ミュート、**S** ボタン=ソロ（そのトラックだけ聴く）
- 音量: パネルのフェーダーをドラッグ、または数値部分をダブルクリックで入力
- トラック追加: **Ctrl+T**。削除: トラック選択して **Ctrl+Delete**

---

## 3. まず通しで聴いて、直す場所に印をつける

1. **Home** で先頭 → **Space** で再生。全体を1回聴く
2. 気になる箇所（発音が変・語尾が途切れる・別の声が混じる・音程が外れる）で、
   その位置に編集カーソルを置き **M**（マーカー挿入。※トラックのMボタンとは別、
   キーボードの M）。マーカーが時間軸の上に立つ
   - マーカーに名前: マーカーをダブルクリック → メモを書く（例「サビ頭 語尾切れ」）
3. マーカー間の移動: **Ctrl+←/→**

---

## 4. 破綻箇所を差し替える（このワークフローの本番）

考え方: 悪い区間だけ「別トラックの良いテイク」で上書きし、境目をクロスフェードで繋ぐ。

### 4.1 差し替えテイクを用意する
- 方法A（推奨）: 自分でその部分を歌って録音 → RVC でルカ声に変換（変換は
  こちらのバッチに投げてOK。変換済み WAV を受け取る）
- 方法B: Synthesizer V 等で打ち込んだガイド → RVC 変換
- どちらも**変換済み WAV**を REAPER に持ってくる

### 4.2 差し替えの実操作
1. **Ctrl+T** で新トラック追加 → 名前 `Vocal fix`
2. 差し替え WAV をそのトラックにドラッグ。**該当の時間位置**に置く
   （マーカーを目印に、アイテム本体をドラッグして合わせる）
3. 位置の微調整:
   - 大まかに合わせたら**ズームイン**（Ctrl+ホイール）して波形の山を目視で合わせる
   - **アイテムを選択 → 左右矢印キーでは動かない**ので、ドラッグ or
     Item Properties の Position 数値で調整
   - スナップが邪魔なら **Alt+S** でスナップ ON/OFF
4. 元の `AI Vocal` の該当区間を**その区間だけ消す/下げる**:
   - 消す場合: `AI Vocal` のアイテムを差し替え区間の**両端で分割**する。
     分割は「カーソル位置で選択アイテムを分割 = **S**」…ではなく **S は split**。
     区間の左端にカーソル → **S**、右端にカーソル → **S**。真ん中の断片を
     選択して **Delete**
   - 下げる場合（安全策）: 消さずに、その区間だけ音量を下げる方が繋ぎが自然。
     ただし2声重なるので基本は消す
5. **クロスフェードで繋ぐ**:
   - 隣り合う2アイテムの端を少し重ねると、REAPER が**自動でクロスフェード**を作る
     （重なり部分に×印のフェードカーブが出る）
   - フェード長の調整: 重なり部分をドラッグ。10〜40ms 程度が目安
   - フェードカーブ変更: フェード部分を右クリック → カーブ形状を選ぶ
     （繋ぎが不自然なら「equal power」系にする）

### 4.3 繋ぎ目が目立つときの対処
- 前後にブレス素材（元歌手の実録ブレス）を挟む
- 差し替えテイクの音量・EQ を前後に合わせる（次章のミックス）
- ピッチが合っていない → 4.4 で補正

### 4.4 ピッチ・タイミングの微修正
- **ピッチ補正**: 差し替えアイテムを選択 → FX（後述）に Graillon 2 を挿す。
  または半音単位のシフトは **Item Properties（ダブルクリック）> Pitch** に数値
- **タイミング（伸縮）**: アイテムの端を **Alt+ドラッグ**でタイムストレッチ
  （長さを変えても音程は保たれる）。アルゴリズムは Item Properties >
  「élastique 3 Pro」を選ぶと歌に強い

## 5. FX（プラグイン）の挿し方 — 全トラック共通

1. トラックパネルの **FX** ボタンをクリック → FX チェイン窓が開く
2. 左上 **Add** → 一覧から選ぶ（検索窓にプラグイン名を打つ）
3. 挿した FX は上から下へ順に処理される。ドラッグで並べ替え、
   チェックを外すとバイパス
4. まず入れる無料FX（`docs/DTM_GUIDE.md` の表からDL・インストール後に一覧に出る）:
   `ReaEQ`（付属）/ `ReaComp`（付属）/ `TDR Nova` / `Graillon 2` /
   `Valhalla Supermassive`

### ボーカルトラック（AI Vocal と Vocal fix 両方に同じ設定）の基本チェイン
順番どおり Add:
1. **ReaEQ**: 一番左のバンドを「High Pass」にして 80〜100Hz 以下をカット
2. **TDR Nova**: こもり(250〜400Hz)と刺さり(2.5〜4kHz)を -2〜-4dB
3. **ReaComp**: Ratio 3:1、Threshold を下げてゲインリダクション 3〜6dB。
   Attack 10ms / Release 100ms あたり
4. （歯擦音が気になれば）**TDR Nova** をもう1つ、6〜9kHz をダイナミックに抑制

### リバーブは「センド」で共有する
1. **Ctrl+T** で新トラック `Reverb`、そこに **Valhalla Supermassive** を Add
   （Mix=100% にする）
2. `AI Vocal` パネルの **IO** ボタン（または右クリック > Sends）→
   Add send to `Reverb`。送る量をフェーダーで調整（控えめに）
3. `Vocal fix` からも同様に send。これで両ボーカルが同じ残響になり繋ぎが自然

---

## 6. 音量バランス（ミックス）

1. `Inst` を基準に、ボーカルが**埋もれず・浮きすぎず**になるよう
   `AI Vocal`/`Vocal fix` のフェーダーを調整
2. サビだけボーカルを上げたい: **オートメーション**を使う
   - トラックパネルの **Env** ボタン（またはトラック右クリック >
     Envelopes）→ Volume にチェック
   - トラック下に出た線を、上げたい区間で**Alt+クリックしてポイントを打ち**、
     ドラッグで持ち上げる
3. 全体が歪む/大きすぎる: **Master トラック**（View > Master Track, Ctrl+Alt+M）
   のフェーダーで下げる。Master に **ReaLimit**（付属）を挿して
   ピークが 0 を超えないようにする

---

## 7. 書き出し（レンダリング）

1. **File > Render**（Ctrl+Alt+R）
2. 設定:
   - Source = **Master mix**
   - Bounds = **Entire project**（または Time selection）
   - Output = 保存先とファイル名
   - Format = **WAV**、24bit、44100Hz
   - Resample mode は既定でOK
3. **Render 1 file** をクリック
4. 個人試聴だけなら Format を FLAC にしてもよい

## 9. つまずきポイント（先回り）

- **音が鳴らない**: Options > Preferences > Device でオーディオドライバ未設定。
  ASIO4ALL か WASAPI を選ぶ。トラックのSがどこか押しっぱなしでも鳴らない
- **ボーカルとインストがズレる**: どちらかが0に置けていない。両アイテムの
  Position を 0 に。それでもズレるなら別々の曲/別キー版を混ぜている
- **キー変更した変換ボーカルを使った**: インストも同じ半音数シフトが必要
  （Item Properties > Pitch）。音質が落ちるので、基本は原曲キーの変換ボーカルを使う
- **プラグインが一覧に出ない**: インストール後に Options > Preferences >
  Plug-ins > VST > Re-scan。64bit VST3 を入れること
- **重くなった**: FX を挿しすぎ。使っていないトラックは削除、
  リバーブはセンドで共有（各トラックに個別で挿さない）
